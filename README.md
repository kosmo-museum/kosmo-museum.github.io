## Как показать на созвоне

**Заранее (один раз):**
1. Создать ключ GitHub: https://github.com/settings/personal-access-tokens/new → Repository access: только `kosmo-museum/kosmo-museum.github.io` → Permissions: **Contents — Read and write**. Если организация попросит одобрить ключ, одобрить его в настройках организации.
2. Открыть админку на ноутбуке, войти, нажать «Опубликовать», вставить ключ, отметить «Запомнить». Проверить, что публикация проходит.
3. Нажать «Сбросить черновик», чтобы начать показ с чистого листа.

**На созвоне:**
1. Зрители открывают приложение по QR (кнопка «Открыть на телефоне» над превью) и не закрывают его.
2. **Сводка:** статистика приложения (демо-данные) и быстрые кнопки.
3. **Главная:** поменять приветствие, включить объявление — превью справа меняется сразу.
4. **Мероприятия → Календарь:** нажать на день → «Создать мероприятие» → название, время, место.
5. **Анонсы и пуши:** включить «Прямо сейчас» и написать текст, или запланировать анонс на ближайшую минуту.
6. **Магазин:** поменять цену товара. **Экспонаты:** поправить текст карточки «Востока» (глаз — открыть её в превью).
7. **«Опубликовать».** Примерно через минуту у зрителей на телефонах без перезагрузки появятся мероприятие и уведомление, обновятся цена и приветствие.

Пока идёт публикация, можно рассказать, как это будет устроено у музея (`docs/admin-production.md`).

## Сайт
Страницы — `site/*.html`, общий слой — `site/assets/site.js` (контент из `app/content.json`, превью `?preview=1`), стили — `site/assets/site.css`. Данные экспонатов — `site/data/exhibits.json` (снимок из приложения: EX, INFO, залы); правки из админки накладываются поверх. Гид открывает экспонат по ссылке `app/?ex=ID`.

## Сборка
```
cd source/app && python3 build.py && cp index.html ../../app/index.html
```
Исходники — `source/`, картинки и модели — `app/`. Старая ссылка музея (perasperadastranew.github.io/romashka/kosmo-museum/deck/app/) обновляется копией `app/` вместе с `content.json`.
