# Музей в кармане — Музей космонавтики

Приложение-гид для Музея космонавтики, прототип студии Perasperadastra.

- Приложение: https://kosmo-museum.github.io/app/
- Админ-панель (в работе): https://kosmo-museum.github.io/admin/
- ТЗ: [улучшения приложения](docs/TZ-app.md) · [админ-панель](docs/TZ-admin.md)

## Сборка
```
cd source/app && python3 build.py && cp index.html ../../app/index.html
```
Исходники — `source/`, картинки и модели — `app/`. Старая ссылка музея (perasperadastranew.github.io/romashka/kosmo-museum/deck/app/) обновляется копией `app/`.
